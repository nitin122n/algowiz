# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Students learning data structures and algorithms, and developers refreshing them. They open the app in the evening or between lectures, on a laptop or a phone, with one algorithm in mind and one question: why does it do that?

## Product Purpose
ALGO-WIZ turns an algorithm's whole run into a recorded sequence of steps that the user can play, pause, step backward, and scrub. Every step carries one plain-English sentence, the active pseudocode line, and live counters. Success is that a student can explain the algorithm afterward.

## Positioning
Every algorithm shares one step contract, so all of them are controlled identically, run entirely in the browser, and can be shared as a URL that restores the data and the exact step.

## Operating Context
Static site, no backend. Runs on desktop and phone widths. Users type their own data, edit boards and graphs, and compare algorithms side by side (race mode).

## Capabilities and Constraints
117 algorithms in eight families: sorting, searching, linked lists, graphs and pathfinding, trees and heaps, dynamic programming, string matching, backtracking and classics. React 18 + Vite + TypeScript, plain CSS, no runtime dependencies beyond React and icon/font packages. Both light and dark themes are required.

## Brand Commitments
Name: ALGO-WIZ. Authors: Mayank Karki, Nitin Kandpal, Swarit Kumar. MIT license.

## Evidence on Hand
No testimonials, user counts, or benchmarks exist; none may be invented.

## Product Principles
1. Step-by-step clarity outranks decoration: the explanation, the highlighted line, and the controls are always readable.
2. Every algorithm feels the same to operate.
3. Color carries meaning in the data; the chrome may be expressive.
4. Nothing is claimed that the product does not do.

## Accessibility & Inclusion
Keyboard reachable controls, visible focus, color never the only signal, reduced-motion respected, usable at 375px.
